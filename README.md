# Disease Statistics Viewer

## About My Project
I developed this project using Flutter to display COVID-19 statistics of different countries. By using the disease.sh API, users can search for a country and view its COVID-19 information.

## Features
- Search for any country by name.
- Display the country name and flag.
- View total COVID-19 cases.
- View active and recovered cases.
- Check total deaths.
- View new cases and deaths reported today.
- Display cases and deaths per million.
- View tests per million and population.
- Show the last updated time.

## Technologies Used
- Flutter
- Dart
- REST API
- HTTP Package
- JSON

## API Used
disease.sh API

## How It Works
First, the user enters a country name in the search box. After clicking the search button, the application fetches the data from the disease.sh API and displays the statistics on the screen.

## What I Learned
Through this project, I learned how to connect an API with a Flutter application, fetch data from the internet, convert JSON responses into usable data, and display the information using Flutter widgets.
